# aText Text Expander

aText is a text expansion and typing automation utility that replaces short abbreviations with predefined phrases, reusable templates, and formatted snippets. It helps users reduce repetitive typing, maintain consistent wording, and organize commonly used text for everyday writing and communication.

## Overview

aText streamlines text entry by converting user-defined abbreviations into longer content. Instead of repeatedly entering the same phrases, users can create snippets and assign short triggers that expand when typed.

The application supports a range of content types and configuration options, making it useful for correspondence, documentation, technical writing, customer communication, and other tasks involving repeated text.

## Text Expansion Workflow

aText uses abbreviations as triggers for inserting predefined content. Users create snippets, assign abbreviations, and configure how expansion occurs.

Depending on the selected settings, a snippet can expand after its abbreviation is entered, after a delimiter is typed, or through a configured shortcut.

This approach is useful for repeated email responses, standard phrases, technical terminology, form entries, and frequently used text blocks.

## Snippet Management

Snippets can be organized into groups to keep related content structured and easy to find. Users can maintain separate collections for different writing tasks and organize their entries around recurring workflows.

The snippet editor provides options for defining abbreviations, editing content, and configuring supported expansion behaviour.

## Formatting and Templates

The rich-text editor supports formatted snippets for situations where plain text is insufficient. Depending on the selected content type, templates can include formatting, images, attachments, and other supported elements.

Reusable templates help maintain consistent wording and presentation across repeated messages and documents.

## Auto-Correction and Typing Rules

aText includes configurable correction and text-entry features that help reduce common typing errors. Users can adjust supported rules and expansion behaviour to suit their preferred workflow.

These settings can be particularly useful when entering frequently repeated terms, standard phrases, and specialized terminology.

## Advanced Automation

The application supports advanced snippet capabilities, including scripting, editable fields, and abbreviation parameters. These options allow users to build more flexible templates and automate certain repetitive text-entry tasks.

Advanced features may require additional configuration and depend on the selected snippet type and application settings.

## Troubleshooting

| Issue | Suggested Check |
| --- | --- |
| A snippet does not expand | Confirm the abbreviation and expansion trigger settings. |
| The wrong text is inserted | Edit the snippet content and verify its assigned abbreviation. |
| Formatting is not preserved | Review the snippet type and the target application's formatting support. |
| A shortcut does not work | Check the assigned key combination and possible conflicts. |
| A script does not run | Review scripting settings and the requirements of the selected script type. |
| Synchronization is unavailable | Check the configured storage location and access permissions. |
